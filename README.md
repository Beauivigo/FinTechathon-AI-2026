## 检查共享底座

共享库使用 Python 3.10+，无第三方依赖。在仓库根目录运行：

```text
python -X utf8 -m examples.contract_demo
python -m unittest discover -s tests -v
```

main 现有 47 项共享接口测试。Demo 展示“日累计 900 元 + 本次 120.50 元”触发待强验证，不执行扣款。接口测试通过不代表模拟银行、六场景业务或 G01—G15 整体验收已完成。

A 的接入顺序：参考 JSON 样例 → 通过 shared 构造/校验请求 → 网关检查 → 业务计算 → 校验并展示结果 → 测试。网络 JSON 用 `loads_request/loads_result`，本地模块用 `adapt_request/adapt_result`。B—E 交业务规则、表格和预期结果，由 A 负责程序导入与校验。

修改样例源后同步导出文件：

```text
python -X utf8 -m examples.module_examples --write
python -X utf8 -m examples.service_examples --write
```

已配置 GitHub Actions，在未来 push/PR 时使用 Python 3.10、3.12 检查契约、样例和演示脚本；本地检查不等于远程工作流已运行。接口变更由 A 同步更新代码、文档、样例和测试，业务负责人核对语义，C 组织回归。
