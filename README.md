# FinTechathon-AI-2026

2026 FinTechathon 银行 AI 智能体项目，目标覆盖全部六个场景。

**统一使用 main。** 已有持久化模拟银行、转账/定时/AA、账单、理财评估与申赎、卡片、订阅、预算及商户六场景基础。“AI银行助手”支持DeepSeek、GLM等国内服务商理解需求、追问和编排；包含完整计划持久恢复、Windows本机登录与手机TOTP、独立后台检查和生日到期待办。付款仍需确认或验证，银行与商户业务仍为模拟。默认接口v1.1，真实TOTP交易支持v1.2，存储v16；用户本人手机绑定与最终体验仍待用户签收。当前发行版为 **2.0.0**：柔彩 UI 视觉系统与统一组件样式，业务、资金、授权、认证与共享接口不变；Windows x64 安装包见发布页。云部署与本人手机现场签收仍按 BLOCKERS 跟踪。

## 启动页面

**普通用户：从[GitHub发布页](https://github.com/Beauivigo/FinTechathon-AI-2026/releases/tag/v2.0.0)下载 YanXing-Setup-2.0.0-x64.exe（本地构建文件`言行-2.0.0-x64-setup.exe`的同字节发布名），在桌面 `other` 中运行“启动言行”。无需预装Python。** 独立安装默认端口8511，数据在当前用户LocalAppData中；从 1.0.x 覆盖升级保留账号、账本、模型配置与快捷方式，不重置日常数据。源码开发环境仍可在项目根目录双击 `启动银行助手.py`。 它优先使用已配置的 `.venv`，已打开时复用现有页面，不启动第二套服务；端口被占用时只提示且不改数据。正常退出请使用页面“退出应用（不是关闭网页）”。

需要 Python 3.10+。源码开发机安装依赖可运行：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-app.txt -r requirements-materials.txt
.\.venv\Scripts\python.exe -m streamlit run app/main.py --server.address 127.0.0.1 --browser.gatherUsageStats false
```

已有 .venv 和依赖时也可运行“启动A演示.ps1”或最后一条命令。打开 [本地页面](http://127.0.0.1:8501)，首次可选择“体验示例账户”或“设置本机账号”；设置时离线保存恢复码并绑定手机验证器，之后密码登录，红色业务使用当次动态码。后台检查在“后台任务与通知”内启用/停止，选择会保存。

以下两条命令仅用于管理员排障；普通用户请使用程序内页面。管理员如需排障，可运行 `.\.venv\Scripts\python.exe -m bank.auth` 初始化一次账号，离线保管恢复码，再到页面登录扫码。后台另开终端运行 `.\.venv\Scripts\python.exe -m bank.worker`；关闭网页仍检查任务，关闭后台或电脑关机则停止。普通用户流程已改为程序内首次设置和后台启停，不要求终端。完整说明见[U1—U5程序内使用说明](docs/U1-U5程序内使用说明.md)。

在“我的 → 高级设置 → 模型设置”中，选择DeepSeek、智谱GLM、通义千问、豆包或Kimi，再保存对应服务商的独立API密钥。支持自定义模型ID，桌宠配置复用仅限DeepSeek。独立密钥按Windows当前用户加密保存，修改只影响后续新请求；部署环境变量优先。详见[配置与使用](docs/AI模型接入与验收.md#2026-10-23-国内多服务商配置)。

## 接口与运行边界

验收输出必须使用新目录，避免覆盖旧证据。共享接口默认 `schema_version="1.1"`，真实TOTP交易使用受控兼容版本`1.2`；字段、版本和样例以接口指南为准。

AA收款单不代表已收款，卡片申请仅受理。后台进程运行时自动检查转账、商户和提醒，生日完整计划可按时准备预算与订单待办；付款仍需当前确认/验证，未实现长期无人值守扣费或真实配送。首次初始化本机身份后启用真实密码登录与手机TOTP；此前为演示验证。通知为持久站内待办，没有短信、邮箱或Windows弹窗送达。

运行库位于被Git忽略的 `runtime/`。重置会清除模拟交易，未知结果应先查询原操作。

模型仅输出有界声明式计划，不执行任意生成代码；工具、身份、授权和审计由可信代码控制。连续5次异常草稿停止本会话，核实后通过“新需求”重开；银行验证锁定与原操作恢复独立处理。已验证的是逻辑隔离边界，未提供独立OS沙箱或生产银行安全认证。
