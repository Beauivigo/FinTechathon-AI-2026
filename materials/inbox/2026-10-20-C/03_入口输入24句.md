# C 第四轮入口输入 24 句 — 阅读版

机器可读字段见 [03_入口输入24句.json](03_入口输入24句.json)。`route(text)` 是纯展示草稿：不调用网关、不写库、不授权。

- 覆盖：账单、转账、卡片、AA、订阅、生日六类；每类正常/缺字段/歧义/取消否定各 1 句，共 24 句。
- 统一提示：ready 的 message 为“路由草稿完整（不代表已授权或资源有效）。”；cancelled 为“已取消当前路由草稿。”。
- 关键区分：**“取消草稿”**（如“不要取消订阅 SUB-E001”→ cancelled，不产生订阅取消请求）≠ **“取消已提交业务”**（如“取消订阅 SUB-E001”→ subscription ready，仍需走原确认流程）。
- **本表只列预期，不写“同预期/通过”**：C 本地实跑结果在 03 JSON 的 `actual`，逐句比对由 `check_c4.py` 计算并写入 `selfcheck.json`。这是按 C-12 要求，避免把结论写死在文档里。

## 边界说明

1. 歧义输入会把冲突字段从草稿中清除，并要求重新明确（与 A 的固定验收 `test_conflicting_values_cannot_reappear_after_followup` 一致），不会带着旧值直接 ready。
2. 取消/否定只清空当前路由草稿；对“取消订阅 SUB-E001”这类已提交业务，必须走订阅模块的取消流程，由路由草稿导航到表单后另行确认。
3. `amount_text` 保留原文（如“200元”），不在路由层换算金额；真实金额校验由既有网关与模块完成。
4. 以上结果不代表已支持任意自然语言、真实模型或六场景自动编排；只是有限中文规则的展示草稿。
5. 本表与 JSON 中的 `actual` 均来自 C 在 `main@22473aa` 上对 `route(text)` 的实跑；是否与预期一致由 `check_c4.py` 计算，不在此表写死。
