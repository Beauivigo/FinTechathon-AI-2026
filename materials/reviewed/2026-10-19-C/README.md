- **C-14／小错误**：R01“放款日含起90日”与例子闭区间端点相差一天。依据多个显式算例与代码，采纳表述为“还款日−放款日介于0至90天，含两端”，如10/1至12/30；不是总共90个包含日期。`out_of_window` 当前只是指向字段的辅助诊断，不能据空列表声称其他键没有超窗记录。
