## 字段与实现

| 业务内容 | 当前承载与校验 |
|---|---|
| 产品 | `wealth.catalog`公开七字段；净值与费率留在内部配置，不扩展契约 |
| 问卷 | `questionnaire_version=wpq_v1`、answers；q1—q5必答，选项必须属于对应题 |
| 评分 | total_score内部存储；`wealth.assess`响应明确返回risk_profile_id、risk_level |
| 申购 | account_id、product_id、risk_profile_id、amount_minor；响应order_id、amount_minor |
| 持仓/赎回 | holding_id、units；响应order_id、units；归属、锁定及份额逐笔校验 |
| 精度 | 金额整数分；费用ROUND_HALF_UP到分，申购持仓4位；共享decimal_string最多8位小数，页面/模型输入另按4位限制，不能把三者混写 |
| 授权/状态 | 原网关红色模拟强验证，幂等键与原请求绑定，unknown查询原操作 |
| 流水/到账 | kind=wealth，不计消费毛支出；当前模拟赎回强验证成功即展示入账，不存在真实T+1等待队列 |

6个产品的内部参数核对见[补测config](../../../docs/evidence/2026-10-23-final-material-probes.json)，全部一致。补测脚本：[verify_final_materials.py](../../../scripts/verify_final_materials.py)。

全部虚构；各数字有确定产品/费率来源，不依赖缺失D第四轮交易明细。

| 步骤 | 产品与计算 | 余额（分） |
|---|---|---|
| 期初 | 独立模拟库1000000，风险R5 | 1000000 |
| 申购 | WP-C02金额50000，费50，净49950，499.5000份 | 950000 |
| 申购 | WP-C03金额200000，费1000，净199000，1592.0000份 | 750000 |
| 第7日部分赎回 | WP-C02赎200份，费0，到账20000；WP-C03此时仍锁定 | 770000 |
| 第30日部分赎回 | WP-C03赎1.6份，毛200，费1，到账199 | 770199 |

期末`1000000−50000−200000+20000+199=770199`，可用770199、预留0；费用合计`50+1000+0+1=1051`。这里的1051只属于A新建样例，不据此推断D缺失原件的3301算错或替D编造原交易。A新样例和原索引虽期末相同，不能混为同一原始证据。
