## 完成范围

- 查询区间内 `direction=debit` 且 `kind ∈ {consumption, subscription, transfer, wealth}`、单笔 `amount_minor >= 500000` 的流水，各生成一条 `anomalies` 记录；同一流水只出现一次，按 `transaction_id` 升序，同一快照重复调用结果一致。
- `anomaly` 仍只有 `transaction_id` 和 `reason` 两个字段，规则编号、金额与阈值写在 `reason` 内（如“大额单笔 6000.00 元 ≥ 5000.00 元（C1-003-R03 分支A）”），**不新增公开字段，共享接口仍为 v1.1**。
- 报告文案由“自动异常检测尚未启用”改为“已启用大额单笔提示（R03 分支A）……其余规则尚未启用，空列表不代表没有异常”。
- 资料账单页展示异常表（流水号、原因）；无异常时提示本区间未发现大额单笔。
- 只提示核实，不拦截、不改账、不删流水、不判欺诈。
