## 设计方向与 token 草案

### 同一套系统中的三种模块气氛

| 系统 | 用户指定原色 | 使用范围 |
|---|---|---|
| B，产品主视觉 | 奶油黄 `#FFFFD0`、天空蓝 `#D8EFFF` | 首页、账户、转账、卡片、AA、预约、订阅、生日、理财、我的及通用表单 |
| A，AI 与智能分析 | 薄荷绿 `#DDFFC2`、浅紫 `#EEE1FF` | AI 入口、助手页面、计划展示与智能理解区域 |
| C，账单与洞察 | 蜜桃粉 `#FFEAE1`、冰蓝 `#B6FAFF` | 当前账单、历史样例分析、预算与财务洞察 |

三组原色作为背景和局部点缀，共用文字、状态、主操作、字体、间距和圆角。采用低饱和的多层径向渐变及中间浅色过渡，避免生硬的双色对切。大面积保持浅色，渐变集中在页头、账户和 AI 重点区域。

### 共用语义值（实施时需核对实际对比度）

| 类别 | 草案 |
|---|---|
| 正文 / 次要文字 | 深墨绿灰 `#24373B` / `#53676A`；不用渐变文字显示余额、金额和提示 |
| 主操作 / 背景 | 深青绿 `#246565` / 近白 `#FCFDFC`；按钮文字需满足实际对比度要求 |
| 状态 | 成功 `#21634B`、警告 `#805E0A`、风险与失败 `#AD323C`；与 A/B/C 底色区分，保留文字和图标 |
| 表面 | 足够不透明的浅色玻璃卡片、柔和细边框、统一方向的淡青灰阴影；无 blur 支持时仍清晰 |
| 圆角 | 控件 12px、内容卡片 20px、重点容器 28px；形成内外层级 |
| 间距 | 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64px；常规内容间距 24–32px |
| 字体 | 复用本地 IBM Plex Sans、Noto Sans SC、思源黑体、苹方、微软雅黑等回退；不下载字体 |
| 数字 | 等宽数字特性、清晰货币单位；长金额允许合理换行，不截断或省略 |
| 字号 | 正文 16px、辅助 14px；页标题约 32–36px，余额重点约 36–44px，按小屏收缩 |
| 动效 | 仅交互引起的 120–180ms 颜色/阴影反馈；不做循环漂浮、发光或多处入场动画，尊重减少动态效果设置 |

先建立可复用的主题和静态样式 token，再用于共享组件与页面。原生主题负责基础控件；用户要求的渐变、背景模糊、阴影和微动效由范围明确的纯视觉样式承担。样式只使用可信固定内容，不拼接金融数据或用户输入。

## 布局与文件范围

桌面内容限制合理最大宽度（约 1280–1360px），保持左对齐和清晰阅读顺序。首页继续保留“账户事实 + AI 入口”的重点区域，随后是常用业务、待处理和近期记录；不增加营销口号、虚构统计或没有作用的装饰卡片。

```text
导航        账户首页 / 当前页面标题
            账户概览（B）           AI 入口（A）
            常用业务与全部服务
            待处理事项              近期记录 / 洞察（C）
```

小屏按相同阅读顺序自然堆叠；主操作保持易触达。宽表格允许自身区域滚动，但不能导致整页水平溢出。
