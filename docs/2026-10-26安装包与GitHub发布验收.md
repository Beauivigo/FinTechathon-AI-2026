# 2026-10-26 Windows安装包与发布验收

言行 **1.0.0** 为当前用户的 Windows 10/11 x64 竞赛演示安装包，内置官方 Python 3.14.10、Streamlit 1.65.0 及42个固定wheel。安装后无需开发环境。银行和资金均为模拟；GitHub版本入口：[v1.0.0](https://github.com/Beauivigo/FinTechathon-AI-2026/releases/tag/v1.0.0)，仓库保持原有私有状态。

## 安装与使用

下载发布页安装器，核对SHA256后运行。三个快捷方式**统一放在桌面 `other` 文件夹**：启动言行、停止言行、卸载言行；桌面根目录和开始菜单不新建入口。`other` 原有文件保留。

用户数据位于 `%LOCALAPPDATA%\言行\data`。正常启动监听 `127.0.0.1:8511`；关闭浏览器不等于退出。通过“停止言行”或页面退出停止本应用。升级及默认/静默卸载保留数据；交互卸载只有明确选择并通过路径/链接校验后才删除本应用数据。

首次设置本机账号与手机验证器；模型设置中选择服务商并自行配置密钥。安装包没有日常数据库、账号、密码、TOTP种子、恢复码或模型密钥。缺少模型凭证显示未配置。桌宠复用是有相应开发机配置时的兼容入口，独立安装使用独立密钥，无桌宠时会明确提示不可用。

## 修正、证据与边界

DeepSeek历史运行 `cd01f692-6dd4-45fe-b808-fda6400cc4be` 在原有阶段修复上限后留下不完整实现；Codex独立接手完成入口、数据隔离、许可、实际安装与发布工具并验收。保留原失败/执行状态，不把其自测写成独立验收。全局流程随后已升级direct-v1，该历史运行没有重新付费派发。

实际验收发现并修正便携Python导入路径、入口落盘、多页面导航及Windows MSIX虚拟LocalAppData误拒绝。最终保留原生main.py入口，在Python启动时统一设置数据目录；同时检查原始和规范化路径的链接。先前失败候选、同进程失败回归和修正后日志均保留，只有本节最终哈希对应交付。

本次没有新增付费银行API测试；既有DeepSeek在线证据保留其原版本边界。本机Windows版本10.0.26200的干净目录/环境检查，不能冒称独立新电脑、所有Windows版本或安全认证。安装器未做代码签名，不能声称已签名发布。

用户本人手机现场签收、第二家模型在线验证仍待条件；PPT≤10分钟、演示视频≤5分钟仍暂缓。安装交付覆盖可运行程序、源码及部署测试部分，不能据此宣布全部参赛材料齐备。技术/安全正文及Word v0.4为本体修复时点，安装交付以本报告及补充说明为准。

Git源码归档遵循仓库文本换行规则；原始载荷与Git源码的部分CRLF/LF不同，81个文件规范化内容已逐一核对一致，详见[源码版本核对](evidence/installer-20261026/source-revision-match.json)。原始字节哈希仍分别保留，未伪称行尾不同的文件哈希相同。

## GitHub CI平台修正

首次推送d8ac0f4的旧CI在Ubuntu运行645项测试，出现4个DPAPI错误和2个相关页面失败，见[首次运行](https://github.com/Beauivigo/FinTechathon-AI-2026/actions/runs/40319839561)。Windows加密保护保持不变；工作流改到Windows，保留全部断言，覆盖Python3.10/3.12/3.14，3.12与3.14另跑13项安装工具回归。此为最终发布验收修正，未改变已通过安装验收的81个应用/资料文件或12个安装源码文件，安装器SHA256保持不变。后续CI实际结果以对应Git提交的Actions为准。

Windows远端复验进一步发现runner默认TEMP使用`RUNNER~1`短路径，触发既定链接/路径保护及一项账本路径比较。CI已统一使用Runner提供的独立长路径临时目录；未放宽生产路径检查、未删除或跳过有效断言。安装包及业务源码仍不变。
