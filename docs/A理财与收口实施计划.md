## 二、工作流 1：理财（主线，约 3 天）

### 1.1 产品与问卷底座（0.5 天）

- 内部产品配置 6 个（WP-C01—C06）：`product_id`、名称、风险、起购、锁定天数、每份净值（分）、申购/赎回费率、费用说明、赎回规则；`wealth.compare` 输出仍只含契约七字段，净值/费率不出现在公开输出。
- 问卷 `wpq_v1`：5 题×4 选项、分值 1—4、总分 5—20、档位 5—8/9—12/13—16/17—18/19—20；`risk_profiles` 表保存版本、答案、总分、档位。
- 存储迁移 v10→v11：新增 `risk_profiles`、`holdings`、`wealth_orders`、内部产品配置；可重复执行、旧库可升级、演示库不动。
- 验收：产品配置与 D 表逐项一致；问卷 10 个边界样例手算一致；迁移重复执行不报错、旧数据不丢。

### 1.2 `wealth.assess`（0.5 天）

- 校验题号/选项存在、5 题必答；未知题/选项、空对象按 `INVALID_REQUEST`；总分→档位，保存 `risk_profile_id`（稳定 ID），绿色写操作需幂等键。
- 验收：5/8/9/12/13/16/17/18/19/20 十个边界；缺题、非法答案拒绝且不落库；同键重放原档案；越权/跨用户不可见。

### 1.3 `wealth.purchase`（1 天）

- 校验：产品存在、风险 `R_u ≥ R_p`、金额 ≥ 起购、账户归属、可用余额；失败码按 D 表（`RISK_BLOCKED`/`LIMIT_EXCEEDED`/`INSUFFICIENT_FUNDS`），确认前拦截。
- 计算：申购费 = 金额×费率，**Decimal ROUND_HALF_UP 到分**；净额 = 金额−费；份额 = 净额÷每份净值，**4 位小数 ROUND_HALF_UP**。
- 执行：红色 confirm+verify；订单、holding、`wealth/debit` 流水、幂等回执、审计同事务；余额与可用同步减少、预留不变。
- 验收：D 算例 1（50000→费 50→499.5000）、算例 3（R2 买 R4 → `RISK_BLOCKED`）、算例 4（起购不足 → `LIMIT_EXCEEDED`）；费用 0.5 分边界；余额不足；同键重放/改内容冲突；失败无流水、无持仓。

### 1.4 `wealth.redeem`（1 天）

- 校验：holding 归属、`确认日 + lock_days ≤ 申请日`（等于当日可赎）、`units ≤ 可赎份额`；失败 `INVALID_STATE`。
- 计算：毛额 = units×净值；赎回费 = 毛额×费率，四舍五入到分；到账 = 毛额−费；份额扣减可至 0。
- 执行：红色 confirm+verify；holding 扣减、`wealth/credit` 流水、订单、审计同事务；T+1 按“模拟即时入账并标注 T+1”实现，页面与对账都写明。
- 验收：D 算例 2（200 份 ×200 → 费 200 → 39800）、5a 锁定拒绝、5b 份额不足；解锁边界（10-26 当日可赎）；部分赎回/清仓；unknown 按原键查询、不重发。

### 1.5 页面与入口（0.5 天）

- 理财页：问卷→评分结果→产品对比→申购（确认/强验证）→持仓→赎回；所有金额/份额来自服务端，不在页面重算；文案标注“虚构/模拟”，不推荐产品。
- 路由：识别“评估风险/买理财/赎回/看持仓”，缺账户/产品/金额时澄清；不猜参数、不直接写账；未实现动作明确提示。
- 验收：Streamlit AppTest 覆盖下单/拒绝/锁定三条页面路径；路由用例与 24 句基线不回归；页面无绕过网关的写入。

## 三、工作流 2：半自动续费（0.5 天）

- 订阅到期生成待办 → 手动触发 → `merchant.order` 红色强验证 → `consume_reserved`；每期独立授权，不做长期免密。
- 只有扣款成功才按 interval 推进 `next_charge_date`；失败/取消不推进；unknown 按原执行键查询，不重扣、不释放；取消后不再登记后续期。
- 验收：对照 B T2/T5/T8：授权通过扣一期、拒绝不扣、过期不扣、unknown 阻断、取消后不扣；页面可演示“识别→核实→提醒→到期→当次确认扣款”。

## 七、风险与处理

| 风险 | 处理 |
|---|---|
| 费用/份额舍入与 D 口径不一致 | 统一用 `Decimal` + `ROUND_HALF_UP`，测试钉住 0.5 分与 4 位小数边界 |
| T+1 模拟被误解为实时到账 | 页面/验收统一写“模拟即时入账，标注 T+1”，对账表注明 |
| 产品配置泄漏到公开输出 | `wealth.compare` 仍只输出七字段；净值/费率只存内部配置 |
| 存储迁移丢旧数据 | v10→v11 只加表/列，迁移可重复，旧库升级测试 |
| 页面自行算金额/份额 | 页面只展示服务端结果；重算逻辑只允许测试脚本使用 |
| 路由猜参数或绕过确认 | 缺字段只澄清；所有写操作仍走网关 confirm/verify |
