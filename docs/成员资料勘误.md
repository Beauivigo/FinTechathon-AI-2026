# 成员资料勘误

README 固定入口。主要在收到、核验、修订成员资料时更新，按日期倒序保留记录。未在当轮检查的成员不推断为已通过或未交付。

- **小错误**：文字、版本、编号说明、引用等，可依据既有结论修正且不改变业务含义。
- **大错误**：会改变资金结果、权限、业务判断、接口语义或验收结论。发现时在对话提醒；有确定依据的直接修正，缺决策的保留待确认。
- 每条保留来源位置、处理依据、状态及后续负责人；业务阻塞统一链接 [BLOCKERS](BLOCKERS.md)。新材料修复后追加日期与解除依据，不删除原发现。
- 缺证据能自行复现的，由 A 直接补测并存档，不为补回成员历史日志或截图退回。证据写明实际执行者和覆盖范围；规则缺失不能用测试补造。
