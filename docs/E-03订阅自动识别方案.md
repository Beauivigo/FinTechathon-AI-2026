## 二、规则映射（E-03 → 实现参数）

| 规则 | 实现口径 |
|---|---|
| 归组 | 同一 `account_id` + 同一 `merchant_name`（仅 `direction=debit`，`kind ∈ {consumption, subscription}`，已入账流水） |
| 最少期数 | ≥2 期；1 期不识别 |
| 周期判定 | monthly：以首期“日”为锚，下一期应落在次月同日（短月截断），实际日期与应到日偏差 ≤3 自然日、允许跨月；yearly：同月同日（闰日/短月截断），偏差同样按 ±3 天 |
| 金额容差 | 逐期比较，`|本期−上期| ≤ floor(上期×5%)`；分母是较早一期 |
| 状态口径 | 只统计成功入账流水（`ledger_entries` 只有成功记账），`failed/cancelled/unknown` 不计期 |
| 下一扣费日 | 保留首期锚日，按 interval 推进，短月归当月末日（与 E-07 修正一致） |
| 输出 | 新建 `candidate` 订阅；`evidence` 写明期数、日期、金额、最大偏差，便于复核 |
| 不做什么 | 不扣款、不提醒、不自动 accept、不复活 `cancelled`、不改已有 `active` |

## 四、算法步骤

1. 读取该账户全部入账流水（不分页截断），按时间排序；
2. 过滤 `direction=debit`、`kind ∈ {consumption, subscription}`、`merchant_name` 非空；
3. 按 `merchant_name` 归组，少于 2 期的跳过；
4. 对每组依次判断 monthly、yearly：
   - 计算每期相对“锚日应到日”的偏差与相邻金额差；
   - 全部满足周期与 5% 容差 → 判为候选，取最近一期金额与下一扣费日；
5. 去重：同账户+同商户已有订阅（任意状态）则跳过；`cancelled` 不复活；重复扫描不新增；
6. 写入 `candidate`，`evidence` 记录期数与偏差；返回创建数量与当前订阅列表。

## 五、实施步骤与每步验收

| 步骤 | 内容 | 验收 |
|---|---|---|
| S1 | 纯识别函数（输入流水快照，输出候选），不碰数据库 | 单元测试覆盖周期/金额/期数边界，结果唯一 |
| S2 | 持久化、去重、幂等；重复扫描不产生重复行 | 同库重复扫描 `created=0`；已有 active/cancelled 不被覆盖 |
| S3 | 入口：按拍板方案接 `subscription.scan` 或脚本；写操作走确认/审计/幂等 | 网关用例：确认后返回候选；同幂等键重放原结果 |
| S4 | 页面：订阅管理页加“扫描自动识别”，展示新候选与依据；agent 意图“识别我的订阅”路由 | 页面可完成扫描→核实→取消；对话可触发（方案 A） |
| S5 | 全链路验收与证据 | 候选→accept→active→cancel→cancelled 全通；证据落 `docs/evidence/` |

## 六、测试用例

| 编号 | 场景 | 预期 |
|---|---|---|
| E3-01 | 两期 2500 分，8/05、9/05 | 识别 monthly，下一扣费 10/05 |
| E3-02 | 仅 1 期 | 不识别 |
| E3-03 | 第二期偏差 3 天 / 4 天 | 3 天通过，4 天拒绝 |
| E3-04 | 金额 +340 分 / +341 分（上期 6800） | 340 通过，341 拒绝 |
| E3-05 | 锚日 31：8/31、9/30、10/31 | 识别 monthly，不因短月断开 |
| E3-06 | 年付同月同日；闰日 2/29 | 识别 yearly，非闰年归 2/28 |
| E3-07 | 混入退款、转账、收入 | 不参与归组 |
| E3-08 | 已存在 active / candidate / cancelled 的商户 | 不重复创建，不复活 cancelled |
| E3-09 | 同一账户重复扫描 | `created=0`，列表不变 |
| E3-10 | 两个账户同商户 | 互不影响，各自识别 |
| E3-11 | 扫描后不产生扣费、不产生提醒 | 余额、订阅状态与提醒表不变 |

## 七、风险与依赖

- 日常演示库没有连续扣费流水时识别不出东西：测试与演示用临时库夹具，不改日常库；如需演示效果，可另建明确标记的模拟账户。

- 年付的日偏差容差 E 未单独给，本方案暂用 ±3 天；实施前请 E 确认一句，避免把“同月同日”放宽成 3 天。

## 八、完成定义

扫描能在临时库稳定产出可复算的候选；候选依据可追到期数与金额；重复扫描幂等；不扣费、不提醒、不复活已取消；页面与（若批准）对话均可触发；全量测试通过并留证据。
