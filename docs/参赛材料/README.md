## 后续修改会影响什么

| 变更类型 | 简介 | 技术文档 | 安全自评 | 需同步的证据 |
|---|---|---|---|---|
| 配色、字号、间距或普通文案 | 通常不变 | 涉及所述页面入口时更新 | 涉及模拟提示、权限提示时更新 | 受影响页面及展示截图 |
| 新增、删除或改变业务能力 | 涉及核心定位时更新 | 功能表、流程及实例 | 涉及新资产或权限时更新 | 对应业务与相关回归 |
| 更换模型或改变对话/计划协议 | 涉及技术描述时更新 | 架构、规划、限制 | 数据出境路径、输出边界及风险 | 对话、安全及受影响真实模型评测；有费用须遵循既有授权 |
| 修改金额、周期、评分或状态规则 | 通常不变 | 算法、例子及边界 | 权限、资金或风险判断变化时更新 | 边界、对账、集成回归 |
| 修改身份、确认、强验证、幂等、审计或密钥 | 通常不变 | 安全设计与架构相关部分 | 必须更新对应章节 | 安全、恢复、资金及相关集成回归 |
| 公网部署、真实银行或真实个人数据接入 | 必须重新核对 | 重新核对架构和范围 | 重新评估身份、数据、部署和生产风险 | 新环境独立验收，不能复用本地模拟结论 |

更新时保留旧验收记录，只在实际复验后替换“当前证据”入口。文档改动本身不要求重复运行全部业务测试；实现行为变化时按受影响范围验证。提交前统一源码、材料、PPT和视频的版本，避免旧截图配新功能。
