## 1. 抽象表达怎么落地

| 现实概念 | 抽象画面 | 为什么这样拍 |
| --- | --- | --- |
| 一句话需求 | 一条长纸带，上面手写“给李明转 200，备注房租” | 话是软的，纸是硬的；话先落在纸上 |
| 任务规划 | 纸带沿折痕折成三角信封 | 折叠 = 把一句话拆成结构 |
| 收款人/金额/账户 | 三枚纸芯片：李明 / 200 / 日常账户 | 三个字段就是三个顶点 |
| 计划锁定 | 三枚芯片吸附到三角顶点，金线缝边 | 三角是最稳的结构 |
| 黄色确认 | 三角穿过黄色圆环，圆环收缩成封口 | 确认 = 穿过一道门，不是弹窗 |
| 回执 | 蜡封压下“确认”，纸带展开成回执 | 盖章 = 把动作变成证据 |
| 800 + 300 | 两条纸点溪流，从左右汇成一条 | 累计不是加法题，是两条水流汇合 |
| 1000 阈值 | 溪流撞上红色圆环，环内变红 | 过线 = 撞线，不是数字变红 |
| 强验证 | 红环旋成红门，门合上再开一条缝 | 红色是门，不是提示条 |
| “今天” | 日历页盖“今天”，再盖 800/300 | 累计口径是“今天”，不是“这一笔” |

## 2. 运镜与动效（不抖）

**只用这 8 种：**

1. **Dolly-in / Dolly-out**：镜头推近纸带、推近 1100，再拉远看全貌。
2. **Orbit**：三角/圆环绕着中心转 8—15°，卡片反向补偿，保持正立。
3. **折纸（Fold）**：纸带沿折痕折起，用梯形/斜切模拟 2.5D，不靠 3D。
4. **形变（Morph）**：黄环收缩成封口；红环旋成红门；圆环开口变成纸带。
5. **绘制（Draw-on）**：金线、红笔、溪流从一端“画”到另一端。
6. **视差（Parallax）**：纸带、三角、背景纸纹分三层，移动速度不同。
7. **Rack focus**：前景回执清晰，背景账本虚化；不靠发光。
8. **Match cut**：三角边 → 账本横线；黄环 → 日历圆章；红环 → 红门。

**明确不做：**

- 不抖镜头、不震屏、不做手持感。
- 不随机画圆环/连线/底部两行字。
- 不用粒子爆炸、霓虹、发光边缘。
- 盖章只做 1.4→1.0 下压 + 纸面阴影凹陷，不做镜头抖动。

## 5. 实现备注

- 纸带/三角/芯片/圆环/溪流全部用 Pillow 或 Canvas 画，不用外部图片。
- 折纸用多边形 + 梯形高光/阴影模拟；不要真 3D。
- 溪流用固定种子的一串纸点，逐帧只改变位置和点亮数量；保证可复现。
- 金线/红笔用 draw-on：每帧只画到当前长度。
- 镜头：dolly/orbit 用整体 scale+crop；不做逐帧随机抖动。
- 音乐：用 `video/bgm_250.wav` 的 0:17—0:42.5 段；圈边界对齐 8.5 秒。
