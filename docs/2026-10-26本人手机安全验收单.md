# 本人手机安全验收单（隔离临时身份）

2026年11月1日修订，按当前欢迎页、表单和授权按钮核对。本单用于准备和执行流程，**本人手机现场扫码、动态码及恢复码操作仍未签收**。简明现场记录见[本人手机验收操作单](本人手机验收操作单.md)；两份文档的未执行项均不能由自动化结果代签。

## 1 适用范围与保密

这是Windows本机单用户模拟银行。电脑浏览器操作页面；手机仅运行验证器扫码和生成动态码。模型不参与本次验收，全部转账从手动表单办理，无需密钥或付费AI。

当前服务仅监听电脑回环地址。电脑浏览器可打开`http://127.0.0.1:8502/`；手机浏览器的`127.0.0.1`是手机本身，不能用它访问电脑。不得为完成本单擅自改成`0.0.0.0`、修改首次设置Host检查或开放局域网/公网；这也不是手机银行部署验收。

- 使用固定的隔离临时身份，不读取、重置或覆盖日常`runtime/sandbox.sqlite3`。所有业务对象、产品和资金均为模拟。
- 二维码、验证器密钥、密码、恢复码和手机动态码只在电脑页面与本人手机验证器中使用，不发给模型、对话、群聊或网盘，不截图/录屏，不写入证据。普通用户名也使用虚构临时值。
- 可保存：日期、代码SHA256、软件版本、隔离数据库路径、步骤实际结果及脱敏操作编号。可记录错误类别，不能保存含秘密的界面或完整后台内容。
- 恢复码每枚一次；绑定验证和交易验证会消费通过校验的TOTP时间步。若隔离身份已经初始化，使用本人保存的临时凭据续接，不重复建号或清库绕过未决事项。

## 2 电脑准备与启动

以下命令均在项目根目录运行，使用项目已有虚拟环境，不复制日常模型配置。源码ZIP的使用者须先按部署说明准备依赖。

1. 只读检查环境：

```powershell
.\.venv\Scripts\python.exe -B -X utf8 -c "import sys,streamlit,pyotp,qrcode; print(sys.version); print(streamlit.__version__)"
```

2. 只读查看本次唯一的隔离身份路径：

```powershell
.\.venv\Scripts\python.exe -B -X utf8 app/phone_acceptance.py --check
```

`path`应位于系统临时目录下的`fintech-phone-acceptance-<项目哈希>/sandbox.sqlite3`，不得在项目目录或日常`runtime`中。首次通常为`exists=false`或未初始化；已初始化时登录续接。该入口不接受自行指定数据库路径。

3. 辅助记录日常数据库文件指纹，完成后可重复核对；不读取或导出数据内容：

```powershell
.\.venv\Scripts\python.exe -B -X utf8 -c "from pathlib import Path; from hashlib import sha256; p=Path('runtime/sandbox.sqlite3'); print('missing' if not p.exists() else sha256(p.read_bytes()).hexdigest())"
```

验收期间不操作日常页面或日常后台。此单一文件指纹只是辅助证据：SQLite的WAL、正在运行的日常进程等可能影响文件状态，不能单靠它推断全部业务/身份是否变化；异常时先核查，不删除任何日常数据来制造一致结果。

4. 启动专用隔离服务，只监听回环，关闭浏览器自动统计：

```powershell
.\.venv\Scripts\python.exe -B -X utf8 -m streamlit run app/phone_acceptance.py --server.address 127.0.0.1 --server.port 8502 --browser.gatherUsageStats false
```

电脑浏览器打开`http://127.0.0.1:8502/`，核对控制台打印的隔离身份路径。若端口占用，可改用未占用的8503等回环端口；不要终止不明进程、修改数据库路径或改成非回环监听。

模拟收款人示例可选列表中的“李明 · 模拟银行甲 · ****9012”；实际以页面可信候选为准，不在聊天中编造收款账户。表单按钮会带金额，修改金额后文字相应变化。

正确码来自本人手机验证器，6位、30秒一轮，客户端允许的相邻步范围不等于允许重复消费。成功绑定验证或交易验证后，等待新码再进行独立验证；连续错误存在锁定限制，不用撞码证明安全。

若有待处理或结果未知而表单不可用，进入“首页”的“待处理操作”，或“操作记录”→“恢复待处理操作 / 查看历史”→“选择原操作”→“恢复选中操作”。在原操作详情点击“查询原操作结果”。恢复不会自动确认；unknown或未查到记录都不能据此换新键重付、释放可能已消费的资金或清库。

重启续接检查可先准备一笔待办，按原命令重新启动本次隔离服务并登录，再恢复原操作；保留对象、金额、备注与原编号，授权过期或状态变化时重新核对/验证。正常退出可从侧栏“退出应用（不是关闭网页）”→“查看未完成待办并准备退出”→“确认退出应用并停止本机服务”完成，仅关闭网页不等于停止后台。

## 4 电脑自动化与手机尺寸布局

可在项目根目录执行以下既有离线检查：

```powershell
.\.venv\Scripts\python.exe -B -X utf8 -m unittest tests.test_u1_setup tests.test_real_auth tests.test_closeout_tooling_20261026 -v
.\.venv\Scripts\python.exe -B -X utf8 scripts/evaluate_closeout_model.py
```

前者使用临时模拟身份检查首次设置、登录、真实TOTP算法、防重放、恢复及隔离入口；后者默认离线，使用脚本化模型回复检查当前业务链，不发送真实模型请求。执行结果按实际输出填写，不把这两条命令当作“本人手机已通过”。不加`--live`、不新建付费授权账本。

手机尺寸布局由电脑浏览器的设备视口或自动化模拟检查，例如320、360、390、430px宽度。逐页核对：欢迎页/设置页不留空侧栏、导航可打开关闭、文字与余额不被截断、卡片堆叠合理、表单输入/核对/验证按钮可到达、无页面整体横向溢出。进行截图检查时不进入会显示真实二维码或恢复码的状态；涉及这些状态仅本人现场观察并记录结果。

这些结果称“手机尺寸布局仿真”，不能称为实体手机浏览器、真实触控/软键盘、系统缩放或移动网络通过。手机作为TOTP验证器的现场结果另列，不能由仿真、自动化临时身份或真实算法检查代替。
