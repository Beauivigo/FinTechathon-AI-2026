## 0. 安全规则（先读）

- 只在**隔离临时身份**中操作；不要打开或重置日常 `runtime/sandbox.sqlite3`。
- 二维码、验证器密钥、恢复码、密码、手机动态码、恢复码截图**不得**发到对话、模型、群聊、网盘、工单、证据文件或截图。它们只在本机页面/手机验证器内使用。
- 可记录：日期时间、Windows 版本、Python/Streamlit 版本、隔离数据库路径、每步通过/失败与界面提示。不可记录：任何秘密、二维码、恢复码、动态码、密码。
- 本应用是本地模拟银行，不连接真实银行或真实资金；本单验证的是本机身份/TOTP/恢复流程与授权边界。
- 恢复码每枚只能使用一次；完成本单会消耗至少一枚。需要重新开始时，关闭隔离页面后删除隔离临时目录，不要删除日常数据库。
- 不在页面输入真实银行卡号、身份证号或真实手机号；使用虚构数据。

## 1. 环境与隔离身份

以下命令都在项目根目录执行；若未激活虚拟环境，把 `python` 换成本项目 venv 的 `.\.venv\Scripts\python.exe`。

1. 在项目根目录确认依赖（只读检查）：

   ```text
   python -B -X utf8 -c "import streamlit, pyotp, qrcode; print(streamlit.__version__)"
   ```

   预期 Streamlit 1.65.x；`pyotp`、`qrcode` 可导入。

2. 查看隔离身份状态（只读，不启动页面、不读取日常库）：

   ```text
   python -B -X utf8 app/phone_acceptance.py --check
   ```

   输出 JSON 中 `path` 指向系统临时目录下 `fintech-phone-acceptance-<项目哈希>\sandbox.sqlite3`；这是本次唯一使用的数据库。首次应 `exists=false` 或未初始化；不会输出任何秘密。

3. 记录日常数据库是否存在及指纹（若不存在可写“不存在”），验收后再比对，用于证明未改日常身份：

   ```text
   python -B -X utf8 -c "from pathlib import Path; from hashlib import sha256; p=Path('runtime/sandbox.sqlite3'); print('missing' if not p.exists() else sha256(p.read_bytes()).hexdigest())"
   ```

4. 启动隔离页面（默认 8502，避免与日常 8501 冲突；只监听本机回环）：

   ```text
   python -B -X utf8 -m streamlit run app/phone_acceptance.py --server.address 127.0.0.1 --server.port 8502 --browser.gatherUsageStats false
   ```

   控制台会打印“隔离身份数据库：…”。若端口占用，关闭占用程序或改 `--server.port 8503` 等；不要改成非回环地址。
