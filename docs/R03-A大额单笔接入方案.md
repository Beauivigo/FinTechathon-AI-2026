## 二、规则落地口径

| 项 | 取值 |
|---|---|
| 适用流水 | `direction=debit`，`kind ∈ {consumption, subscription, transfer, wealth}` |
| 阈值 | `amount_minor >= 500000`（5000.00 元，闭区间含等于） |
| 统计范围 | 当前请求的 `account_id` 与 `[start_date, end_date]`（上海日期，含两端）；沿用 `analyze` 现有过滤，不另取历史 |
| 排除 | `credit`、`refund`、`income`；预算预留不产生流水，天然不参与 |
| 输出 | `anomalies: [{transaction_id, reason}]`，按 `transaction_id` 升序，保证同一快照结果稳定 |
| reason 格式 | `大额单笔 6000.00 元 ≥ 5000.00 元（C1-003-R03 分支A）` |
| 报告文案 | 改为“已启用大额单笔提示（R03 分支A）；借贷配对、跨期退款、理财收益率等规则未启用，空列表不代表没有异常” |
| 边界 | 不判欺诈、不拦截、不改账、不删流水；只提示核实 |
