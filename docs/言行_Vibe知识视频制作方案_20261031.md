## 0. 一页结论

这次不做“产品演示 + 大字幕”，也不做“玻璃拟态 + 发光粒子”。  
做一部 **“深色档案纸上的银行机制片”**：

- **背景**：flat `#0B0D12`，无渐变、无星点、无粒子、无辉光、无 3D。
- **主视觉**：米白纸张 `#EDE4D3`、墨色字、哑金 `#C9A96A`、红印章 `#B53A2F`。
- **物件**：文件夹、索引卡、账本、回执纸条、红绳、黄铜夹、印章、剪刀、钥匙、铃。
- **文字**：8 张艺术字以内；其余靠画面和物件讲；不做逐句字幕。
- **声音**：一首 113 BPM 的暗色电子曲（《We Never (Remix)》风格），纸声、盖章声、打字机声做节奏。
- **时长**：2:50 = 20 圈 × 8.5 秒；用原曲的 8.5 秒循环做章节单位。

一句话：**把“权限链”拍成一张在深色桌面上被反复盖章、穿线、归档的纸。**

## 2. 视觉方向：深色档案纸

### 2.1 背景规则（硬约束）

- 底色：`#0B0D12`，全片一个色，不换。
- 不加渐变、不加暗角、不加光晕、不加星点、不加粒子、不加漂浮灰尘。
- 只允许一层 **静态** 纸纤维噪点，透明度 3%，生成一次，不逐帧变化。
- 一条 1px 哑金细线，固定在 y≈70%，透明度 30%，作为“桌面边缘/账本横线”。
- 背景永远不动；所有运动来自前景的纸、墨、章、绳。
- 禁止：霓虹、玻璃拟态、冰霜、3D 透视、镜头光斑、发光边缘、居中大标题 + 渐变背景。

### 2.2 色板

| 名称 | 色值 | 用途 |
| --- | --- | --- |
| 桌面 | `#0B0D12` | 全片背景 |
| 纸张 | `#EDE4D3` | 索引卡、账本、回执 |
| 纸阴影 | `#050609` | 纸下的紧阴影，2—6px |
| 墨色 | `#141414` | 纸上的正文 |
| 哑金 | `#C9A96A` | 标题、细线、页码、关键数字 |
| 印章红 | `#B53A2F` | 确认/拒绝/挂失/强验证 |
| 辅助灰 | `#8A8AA0` | 注释、英文小字 |

### 2.3 物件库

- **文件夹**：六个场景各一个 manila 文件夹，标签手写体；用于开场“6 个入口”。
- **索引卡**：一句话需求、知识点卡、边界卡。
- **账本**：横线纸、页码、合计栏；用于累计 800+300、回执、可信层。
- **回执纸条**：窄长纸带，打印体；用于转账回执、R3 申购。
- **红绳**：连接“模型—网关—账本”，也用于绑文件盒；不是发光线条，是棉线。
- **黄铜夹/尺/锁/铃/钥匙**：小道具，负责“确认/拦截/到期/验证”的动作。
- **印章**：确认、回执、不匹配、挂失、强验证、查原操作；每次盖章都是画面重音。
- **剪刀**：剪断订阅循环的纸带。
- **纸带循环**：订阅的“首尾相接”用一条纸带弯成环，剪断后落下。

### 2.4 字体

- 标题/片名：**Noto Serif SC 900**，哑金 `#C9A96A`。
- 正文/注释：**Noto Sans SC 500/700**，纸上是墨色，深色底上是米白 `#EAEAF2`。
- 英文小字：**EB Garamond italic**，只出现在片名卡和片尾，不逐句对照。
- 数字：等宽字体或大号粗体；`800`、`300`、`1100`、`1000` 要大。

### 2.5 动效手感

- 纸从侧边滑入，带 0.5—1° 微旋转；落定时有 2—3px 回弹。
- 盖章：快速下压 + 0.1 秒定格 + 纸面轻微凹陷（阴影变化），不要爆炸粒子。
- 红绳：逐段延伸，像被人从一头拉过去；不是发光路径。
- 账本翻页：整页翻起，露出下一页的横线；不要淡入淡出。
- 数字：在纸面上滚动计数，最后一下“砸”在纸上。
- 转场：从内容里长出来——文件夹合上、纸卡翻面、回执卷起、账本合上；禁止黑场淡入淡出。

### 2.6 强动态（v5 反馈后加）

- **不抖镜头**：只用推近/拉远、平移、环绕、折纸、形变、视差、绘制；转场 0.1 秒运动模糊；**不做镜头抖动/震颤**。盖章只做 1.4→1.0 下压 + 纸面凹陷。
- **六格功能**：卡片从左右两侧飞入，带 ±7° 旋转和回弹；标题下金线扫过。
- **一句话卡片**：从右侧飞入，带 5° 旋转，落定回弹；结尾甩出。
- **文件柜**：抽屉拉开用 ease-back 回弹；盖章时柜体下压、纸面轻微凹陷。
- **账本**：800/300/1100 数字滚动；红笔快速划断；印章从 1.55 倍下压到 1.0。
- **片尾**：大标题从 1.12 倍拉回 1.0，印章下压；**大标题只在片尾出现一次**。
- **禁止**：随机圆环、卡片到抽屉的连线、背景横线、底部两行字。

## 7. 技术实现

### 7.1 工程结构

```text
video/
├── index.html          # 所有场景 + window.render(t)
├── script.md           # 本片文字/注释表
├── storyboard.md       # 29 镜分镜
├── NOTES.md            # 事实、数字、许可、待确认
├── assets/             # 纸纹、印章、字体（本地）
└── out_frames/         # 渲染帧
```

### 7.2 渲染规则

- 单文件 `index.html`，Canvas 2D；不用 WebGL、不用第三方动画库。
- 暴露 `window.render(t)`：给定秒数画该帧；所有随机数固定种子；不用计时器；帧间不保存状态。
- `document.fonts.ready` 后再开始截图，避免前几帧默认字体。
- Canvas 文字手动换行；禁止依赖浏览器自动换行。
- 纸张纹理只生成一次，作为静态 pattern；背景不逐帧变化。
- 先做 3 张关键静帧给用户看：
  1. 2.8s 六格功能总览（六个文件夹 + 每格一行功能）。
  2. 0:57 “800+300=1100”账本页（红笔划断）。
  3. 2:42 片尾卡（全名 + 主张）。
- 3 张过了，再做 0:00—0:15 的 15 秒样片；样片过了再全片。

### 7.3 渲染命令（skill 脚本）

```bash
# 逐帧渲染
python scripts/render_frames.py index.html out_frames/ --fps 30 --duration 170

# 合成 BGM（113 BPM，段落对齐分镜；当前用 sound-alike，原曲到位后替换）
python scripts/synth_bgm.py bgm.wav --bpm 77 --duration 170 --sections storyboard.md

# 合成 MP4（-14 LUFS）
bash scripts/build_video.sh out_frames/ bgm.wav final.mp4

# 自检
python scripts/qa_check.py final.mp4
```

> 本机当前只落了 skill 的核心文档；`scripts/` 和 `assets/template.html` 需按 `vendor/vibe-knowledge-video/SOURCE.md` 的 clone 命令补全后再跑。

## 8. 资产与事实

### 8.1 资产

- 纸纹：Canvas 生成静态噪点，或 CC0 纸纹；3% 透明度；不逐帧变化。
- 印章：Canvas 画不规则红框 + 手写体字；每个章做 2—3 个微小旋转版本，避免复制感。
- 红绳：Canvas 贝塞尔曲线 + 细阴影；不要发光。
- 字体：Noto Serif SC 900 / Noto Sans SC 700 / EB Garamond italic；本地加载，确认许可。
- UI 证据窗：准备 4 张真实截图（转账回执、红色强验证、生日计划、操作记录），成片按需用 1—3 张；统一裁切、细金边、轻微透视；不露姓名/账号/密钥。
- 不用真实银行 logo、真实卡号、真实手机号、真实人名。

### 8.2 事实

- 六个场景：转账、账单、理财、卡片、订阅、生日。
- 累计规则：同一用户当日已付 + 本次；800 + 300 = 1100 > 1000，进红色。
- 理财：R3 只能买 R1—R3；R4 不匹配拒绝；6 个虚构产品，不承诺收益。
- 订阅：同商户 ≥2 期、周期偏差 ≤3 天、金额容差 5%；识别不等于代扣。
- 生日：保存计划不付款；预算预留只占可用余额；下单还要当前验证。
- 未知结果：不重试，先查原操作，不换键重付。
- 技术：700+ 回归、5 项干净启动；当前只有 DeepSeek 留下在线记录；本人手机验收待完成；安装包未签名。
