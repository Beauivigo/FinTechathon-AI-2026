## 五、1.0.x → 2.0.0 覆盖升级

- 升级前在桌面 `other` 中运行“停止言行”。安装器 `.onInit` 用 `launcher/stop.py --check --quiet` 检查运行中实例，运行中则中止安装并提示，不强制结束进程。
- 安装目录、卸载登记键与三个快捷方式沿用既有约定；`InstallDirRegKey` 读取既有安装位置，覆盖同一目录。
- 数据目录不在安装目录内，安装过程不写入、不删除、不重置；账号、密码、手机 TOTP 绑定、账本、流水、计划、通知、预算预留与模型配置保留。
- 卸载默认保留数据；交互卸载只有在明确选择删除且路径/链接校验通过时才清理本应用数据；`other` 文件夹与其他快捷方式不受影响。
