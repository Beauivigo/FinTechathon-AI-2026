## V1 只读解析验收（2026-10-14）

已实现 [material_check/reader.py](../material_check/reader.py)，不接金融网关，不输出正式 transaction。调用 `read_workbook(path)` 读取固定字节快照；`parse_bytes(content)` 可直接解析已有 bytes。每格保留位置、读取值、Excel 类型、数字/日期显示格式、公式及保存缓存；日期保留原来的无时区表示，不转换为 occurred_at，也不把午夜认定为真实成交时间。Excel 数字保留读取库解码后的数值，不承诺保留原 XML 数字文本；金额单位和分位校验留给 V2。

读取范围为当前 V1.1 表结构：10 张表的主表头按名称定位，次级表和说明仍保存在原始单元格集合中。支持列重排、标题前置、数据增加；不固定 15 行。保留缺字段行和未知单格行供后续检查，只把明确单格说明分开存放。缺表保留其他可读表，缺列或重复/歧义表头时停止该表的流水字段映射，同时保留原始单元格，不静默采用最后一列。

内部返回对象包含 `source_sha256/source_bytes/sheets/ledger_rows/issues/notes`；路径入口还返回 source_path 和 source_changed。source_changed=true 表示磁盘已更新，结果仍只属于原指纹；null 表示结束时无法复读确认，不能称文件未变。issues 仅包含读取结构问题，空列表不代表业务字段、公式或账户映射已合格。V2 再根据保留信息判定规则问题。

读取不执行公式、宏或外部链接，不保存工作簿。文件损坏、格式不支持或加密导致读取失败时抛出 ReadError，不返回部分成功。设置技术容量上限：文件 20 MiB、ZIP 解压总量 100 MiB、10000 个 ZIP 条目、单表 20000 行/200 列、各表矩形范围合计 500000 格；超限明确拒绝，不截断读取。这是本地资料工具的技术限制，不是金融业务规则。
