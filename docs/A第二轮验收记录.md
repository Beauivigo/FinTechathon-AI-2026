## 4. P0 接口交接核对与当时的差距

| 位置 | P0 核对结论 | 后续处理 |
|---|---|---|
| 请求构造 | 复用 adapt_request，程序生成编号，金额为整数分，身份作为服务端参数 | P1—P3 沿用，不让页面或模型生成可信身份/资源 |
| execute / authorize | 现有测试替身入口与内部文档的参数形式一致；authorize 结果关联保存的原请求 | 持久化网关继续复用此约定 |
| 资源快照 | get_context 已返回所有必需数组；账户不包含余额 | P1 通过 account.balance 单独查余额 |
| 五个首批公开动作 | 共享库均有定义；只有 transfer.create 是写操作 | 当前替身只实现 payee.resolve 和 transfer.create，其余查询待 P1 |
| 资金服务 | post_funds 有内部协议和命令/回执校验，没有账本实现 | P2 实现配对记账、事务与子动作去重；不向模型开放 |
| 权限与日累计 | required_gate 要求可信累计并含本次；现有演示传入 0 | P3 接数据库累计，最终授权时重新计算 |
| 结果状态 | pending 必须来源 gateway；成功来源 sandbox/bank；unknown 使用 RESULT_UNKNOWN | 业务结果必须经过校验；持久化成功必须在事务提交后展示 |
| 异常恢复 | 当前 controller 保留 unknown，但无原操作查询；契约不允许后端 unknown 回到待确认 | P4 分离客户端未收到回执与后端业务状态，按持久化原记录恢复 |
| 重试后授权 | execute 重试回执可关联本次 request_id；authorize 仍关联原请求 | P4 恢复原请求后再校验授权响应，不能强行改写原记录 |

此次没有发现需要修改 v1.1 字段、状态或入口签名才能开始 P1 的冲突。上述差距属于计划内待开发能力，不删除原测试，不降低幂等、授权、事务或来源约束来迁就实现。

## 5. 已采用的实施选择与待复核假设

### 5.1 实施选择

继续 Python + 现有 Streamlit，同进程函数调用；P1 使用标准库 SQLite；P0—P6 继续离线转账解析，不要求模型密钥；服务端固定模拟身份，强验证显式标记 demo_otp；继续 main 按批次推进。

这些是开工选择。P0 时只记录；P1 已创建模拟数据库和种子余额，新的授权控制仍待 P3。

### 5.2 首批数据

| 对象 | 标识/对应关系 | P1 已导入的初始状态 | 复核人 |
|---|---|---|---|
| 当前用户 | demo_user_a | 固定服务端模拟身份 | B |
| 付款账户 | demo_account_a | 余额/可用 200000 分；预留 0 | B/C |
| 李明 | demo_payee_li → demo_account_li | 收款账户初始 0，归其他模拟用户，尾号 9012 | B/C |

| 小王二 | demo_payee_wang_2 → demo_account_wang_2 | 初始 0，尾号 5678；与前者同名 | B/C |

当前用户、付款账户及 payee_id 沿用第一轮；P1 将收款账户映射和余额保存为虚构种子数据，尚无资金执行能力。P2—P3 的目标算例：A 向李明转 200 元，确认前 2000/0，完成后 1800/200；重放同一操作后仍为 1800/200。

### 5.3 暂定参数

| 参数 | 本次选择 | 依据与边界 | 复核状态 |
|---|---|---|---|
| 初始余额 | A 2000 元，各收款账户 0 元 | 方便手算；可换种子，不能重置运行中账本 | B/C 未执行 |
| 日累计范围 | 同一用户在上海当日、其全部付款账户的成功对外转账支出 | 保守跨账户汇总；同一业务只算一次，执行日重查 | B 未执行 |
| 授权有效期 | 10 分钟 | 沿用第一轮演示；过期不执行，不静默续期 | B 未执行 |
| 无效模拟验证锁定 | 同一挑战连续 5 次后 blocked / SAFETY_LOCKED | 仅统计所属用户；新控制待 P3，不代表完整账户风控 | B 未执行 |
| 并发处理 | 最终授权与记账在同一短写事务内串行核对 | 待确认不长期占锁/占额度；若以后异步放行须统计并发预占 | A 待 P3 实现，B/C 待验 |

接口已经确定的规则不属于可随意调整的默认值：金额整数分、累计含本次 ≤1000 元待确认/超过需强验证、身份/归属检查、稳定幂等键、双边事务、未知结果先核实、非成功不能显示成功。这些继续遵守现有契约。
