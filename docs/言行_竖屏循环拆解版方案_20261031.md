## 2. 新片规格

- 画幅：1080×1920，30fps，H.264 + AAC。
- 时长：2:50 = **20 圈 × 8.5 秒**。
- 音乐：113 BPM，4/4，F 中心（实测 F/A/C 最强）；具体和弦以原曲为准，不在画面上标错和弦。
- 画面：flat `#08090D`，金色 `#D6A84F`，暖白 `#F4E7D0`，红 `#C04A3A`，绿 `#6F8F6A`，黄 `#C9A15A`。
- 无渐变、无粒子、无辉光；只有金圈、刻度、弧线、卡片、字。
- 字幕：每圈 1—2 行，≤14 字；关键词用金色/红色。
- 口播：默认无；如果要参考视频的解说感，另出一版旁白。

## 3. 视觉系统：一个金圈，三种权限

```
          ① 入口 / 01/20 圈
        ┌─────────────────┐
        │   绿 · 自动       │
        │  ╭───────────╮  │
        │  │  800+300  │  │
        │  │   1100    │  │
        │  ╰───────────╯  │
        │  红 · 强验证  黄 · 确认 │
        └─────────────────┘
             大字：权限看今天
        进度：01/20 圈
```

- **外圈**：20 段刻度，对应 20 圈；当前圈金色，其余暗金。
- **三段弧**：绿（自动）/ 黄（确认）/ 红（强验证）；弧线随当前动作点亮。
- **圆心**：当前圈的关键数字（800+300、1100、R3/R4、1000）。
- **请求卡**：一张小纸卡从左侧滑入，沿圈走到当前弧；不画连线。
- **章节标签**：顶部 `① 入口`，随圈切换。
- **圈数**：右上 `01/20 圈`，底部 20 段进度。
- **底部**：只留 1—2 行大字；不放英文角标、不放两行注释。

## 4. 运镜规则（按 113 BPM / 8.5 秒一圈）

| 运镜 | 什么时候用 | 具体做法 |
| --- | --- | --- |
| 推近（push-in） | 每圈开头 | 1.00→1.06，0.4 秒，落在第 1 拍 |
| 拉远（pull-back） | 一圈结论 | 1.06→1.00，0.5 秒，落在第 13—16 拍 |
| 环绕（orbit） | 请求卡沿圈移动 | 圆盘整体旋转 3—6°，卡片反向补偿，保持正立 |
| 圆环填充 | 权限变化 | 弧线从 0 填到当前段，填充与鼓点同步 |
| 卡片滑入 | 新对象出现 | 从左侧/底部滑入，0.3 秒，落在小节头 |
| 竖屏摇 | 从圆盘到字幕 | 镜头 y 轴下摇 80—120px，0.5 秒 |
| 数字 punch | 1100 / R3 / 1000 | 数字从 0.9→1.05→1.0，落在第 1 拍 |
| 匹配剪 | 圈与圈之间 | 金圈刻度 → 账本横线 / 卡片边 → 抽屉边 |

**卡点网格：**

- 1 拍 = 0.531 秒；1 小节 = 2.124 秒；1 圈 = 8.5 秒。
- 强卡点：每圈第 1 拍（8.5 秒一次）。
- 中卡点：每 2 拍（1.06 秒）或每 4 拍（2.12 秒）。
- 不每一拍都切；一圈内最多 4—6 个动作。

## 6. 文字与字幕

- 每圈 1—2 行大字；一行 ≤14 字。
- 关键词：数字（800/300/1100/1000）、权限（绿/黄/红）、动作（确认/强验证/拒绝）。
- 不逐句字幕；没有口播就不需要台词墙。
- 章节标签只换文字，不换位置：`① 入口`、`② 转账`、`③ 账单`、`④ 理财`、`⑤ 卡片·订阅`、`⑥ 生日`、`⑦ 可信层`、`⑧ 收尾`。
- 圈数：右上 `01/20 圈`；底部 20 段进度。
- 全名只出现两次：02 圈标题、20 圈片尾。

## 7. 声音：先解决“是不是原曲”

你传的 MP4 **是带解说的参考视频**，音轨是单声道，里面有人声 + BGM，不是纯音乐。  
要“根据这个音乐”精确卡点，有两条路：

1. **你提供纯 BGM 文件**（MP3/WAV/FLAC），我按原曲波形重新找 8.5 秒循环点，替换现在的 sound-alike。
2. **没有纯音轨**：我继续用 113 BPM / F 中心的 sound-alike，只能做到 BPM、调性、气质接近，不是原曲。

另外，参考视频是**有解说的**。言行这条我建议先做**无口播版**（BGM + 大字 + 音效），和前面的方案一致；如果你要参考视频的“讲解感”，需要另写 20 圈解说稿并配音。

## 8. 制作方式

- 竖屏 1080×1920，30fps，20 圈 = 5100 帧。
- 先用 Pillow 出 3 张竖屏风格帧：
  1. 01 圈“6 个入口”
  2. 05 圈“800+300=1100”
  3. 20 圈片尾
- 风格帧过了，出 **2 圈 = 17 秒**竖屏样片（不是 15 秒，17 秒正好 2 个 8.5 秒循环）。
- 样片过了，再扩 20 圈全片。
- 如果走 Canvas/Playwright，用 skill 的 `window.render(t)` 管线；如果继续 Pillow，用 `vertical_style.py` 扩成 `vertical_render.py`。
