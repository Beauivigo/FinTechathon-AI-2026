## 如何使用

沿用根目录的“启动A演示.ps1”，或：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-app.txt -r requirements-materials.txt
.\.venv\Scripts\python.exe -m streamlit run app/main.py --server.address 127.0.0.1 --browser.gatherUsageStats false
```

侧栏新增四页：

- **资料账单**：选择 C 的三个资料账户及 2026 年 8/9 月。固定读取仓库同级 `群组资料/B` 和 `群组资料/C` 的已核对版本；文件缺失或指纹变化会拒绝生成报告。它不依赖运行库、不创建可付款余额。
- **产品对比**：选择工程模拟产品查看风险、起购金额、锁定天数和说明。三个样例不代表 D 已正式交付；不执行评分、收益预测或申赎。
- **卡片管理**：选择模拟卡及动作，提交后核对卡片与目标状态，再点模拟验证。解挂后的状态是 frozen，需另发起解冻。卡片状态尚未关联所有付款限制。
- **AA 收款**：按顺序选择演示联系人、输入总额，先查看分摊，再确认创建。只保存本地收款单，不发送微信/短信、不发起付款、不修改余额。

卡片和 AA 共用原 Conversation 的发送、授权与恢复逻辑。刷新后从“恢复卡片 / AA 操作”选择原操作；未知结果先查询，不能换键重发。同一浏览器会话切换转账与新页面，也不能绕过待核实状态。转账页仅恢复转账记录，避免误把卡片回执显示为转账。

## 自动验收入口

```powershell
.\.venv\Scripts\python.exe -B -X utf8 -m examples.five_step_acceptance
```
