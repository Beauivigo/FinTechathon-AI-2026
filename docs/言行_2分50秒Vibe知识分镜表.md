# 言行 · 2 分 50 秒 Vibe 知识分镜表

- 项目：**言行——融合任务规划与分级授权的多场景银行AI智能体**
- 版本：v1.0（2026-10-31）
- 风格：Vibe 知识大赏 / 电影感知识短片
- 时长：2:50（170 秒），29 镜
- 声音：**无旁白**；纯器乐 BGM 76—78 BPM
- 画面：深蓝黑 `#0A0A1E` + 金 `#C9A96A` + 米白 `#F2EEE3`；中央抽象动画，少量艺术字
- 真实 UI：只做 1—2 秒“证据窗”，不做全屏录屏、不做字幕墙
- 配套 CSV：`言行_2分50秒Vibe知识分镜表.csv`

> 这不是“产品演示 + 大字幕”，而是“把银行 AI 的机制拍成一部抽象短片”。  
> 画面负责讲机制，文字只负责钉住 6—8 个记忆点；其余交给 BGM、动效和声音设计。

## 一、为什么这样改

我按你提示去看了 Vibe 知识大赏的拆解资料，之前那版“口播/字幕 + 全屏录屏”确实偏了。这类片子的实际做法是：

- **2:00—2:45**，1920×1080，30fps；无旁白，纯器乐 BGM **76—78 BPM**。
- 深蓝黑底 `#0A0A1E`，五区布局：水印 / 顶标签 / 中央动画 / 注释带 / 底部字幕带。
- 画面必须一直在动：相邻帧差异均值约 **3.97**，静止秒 **<25%**。
- 六段叙事：冷开场钩子 → 真实锚点 → 机制动画 → 反直觉转折 → 现实落点 → 声明/引用收尾。
- 常见做法是 **Canvas/HTML 代码逐帧渲染**，再用 ffmpeg 合成；不是剪映里堆素材。

参考：
- [vibe-knowledge-video](https://github.com/xiazhuo123456789/vibe-knowledge-video)：拆了 8 条原片、1091 帧，给出 76—78 BPM、五区布局、运动密度等实测规范。
- [vibe-knowledge-film](https://github.com/HeyChengC/vibe-knowledge-film)：两种画风“夜曲/寓言”，Canvas + JS 代码生成，先出 30 秒样片再全片。

> 关于字幕：原片其实有一条很薄的双语字幕带，但它不是“逐句台词墙”。你说的大概率是“没有口播、没有字幕讲解”。我这版只保留 **6—8 张艺术字 + 必要注释**，不做逐句字幕。

## 二、视觉世界

### 2.1 一句话

**把“银行 AI 的权限链”拍成一条发光的流水线：请求变成纸卡，纸卡穿过三道门，最后落进账本。**

### 2.2 五个固定区

| 区域 | 内容 | 规则 |
| --- | --- | --- |
| 左上水印 | 言行 / 本地模拟 | 20% 透明度，全程常驻 |
| 右上标签 | `01/06` 章节号 | 只换数字，不换位置 |
| 中央 | 抽象机制动画 | 占画面 60%，一直在动 |
| 下方注释带 | 一行短注释 | 最多 18 字，出现 1.5—2.5 秒 |
| 底部 | 艺术字/关键词 | 只在 6—8 个记忆点出现 |

### 2.3 色彩

- 背景：`#0A0A1E`（深蓝黑），不是纯黑。
- 主光：`#C9A96A`（旧金），只给“权限/账本/关键数字”。
- 文字：`#F2EEE3`（米白），标题可带轻微发光。
- 产品色：只放在“证据窗”里，小面积出现；柔彩和深色底形成反差，不整屏铺。

### 2.4 真实 UI 怎么用

不做全屏录屏；只做 **4 个 1—2 秒的证据窗**：

1. 转账回执（授权级别 + 金额 + 状态）。
2. 红色强验证页（只露“红色/验证”局部）。
3. 生日计划摘要（预算 + 待办）。
4. 操作记录/回执（trace/编号局部）。

证据窗统一处理：圆角 16—24px、细金边、轻微透视、放在画面右下或左侧，像“从系统里抽出来的一张纸”。

## 五、文字规则

- **艺术字 8 张以内**：一句话、拒绝、800+300=1100、红色强验证、不匹配、识别≠代扣、计划≠付款、未知不重试、模型可以错钱不能错。  
  实际选 6—8 张，不要全上。
- **注释一行**：最多 18 字，出现 1.5—2.5 秒；不同时出现两条以上。
- **不做逐句字幕**：没有口播，就不需要把每句话打出来。
- **数字必须真**：700+ 回归、5 项干净启动、6 个虚构产品；录制当天核对。
- **全名只出现两次**：片头 0:10—0:15、片尾 2:42—2:50；其余地方用“言行”。

## 六、BGM 与声音

- **76—78 BPM**，纯器乐；暗色氛围 / 极简电子 / 新古典，不要 lo-fi 鼓点铺满。
- 结构：0:00—0:15 drone；0:15—1:10 钢琴/脉冲进入；1:10—1:43 织体加密；1:43—2:16 抽空、留 piano；2:16—2:35 build；2:35—2:50 stop + 最后一记。
- 卡点不在“每拍切”，在 **8/16 小节换机制**：入口坍缩、三道门、1100 断线、R4 撞墙、剪断循环、保险库合上。
- 音效：玻璃、纸张、印章、锁链、冰裂、剪刀、铃、钥匙、低频脉冲；音量低于 BGM 6—10 dB。
- 混音：-14 LUFS / -1 dBTP；无旁白，BGM 可以比口播版更靠前。

## 七、制作方式

推荐 **代码生成**，和 Vibe 知识大赏的做法一致：

1. `video/index.html` + Canvas/JS，暴露 `window.render(t)` 纯时间函数。
2. 每个场景一个 `draw(t)`；用固定种子随机数，保证每次渲染一致。
3. Playwright 逐帧截图（30fps），ffmpeg 合成 MP4。
4. BGM 用 `synth_bgm` 或授权曲；音效单独轨，最后混音。
5. 先出 **15—20 秒样片**（入口坍缩 + 三道门 + 1100 断线），确认画风再全片。

> 如果团队里没有动效开发，退一步用 After Effects/Figma + 剪映也能做，但“一直在动”的密度会难很多；代码生成反而更稳。
