## 完成范围

- **前置校验在确认前**：持仓归属、账户一致、`state=open`、`确认日 + lock_days ≤ 申请日`（等于当日可赎）、`units ≤ 持有份额`；锁定/份额不足在 `binding` 阶段直接 `INVALID_STATE`，不生成挑战、不扣份额。
- **金额**：毛额 = units×每份净值；赎回费 = 毛额×费率，`Decimal`/`ROUND_HALF_UP` 到分；到账 = 毛额−费。
- **落账**：holding 扣减（可至 0 转 `closed`）、账户 `balance`/`available` 同增、`wealth/credit` 流水、订单与审计同事务。
- **T+1**：按“模拟即时入账、页面与文档标注 T+1”实现。
- **红色流程**：confirm→verify（`demo_otp`）；拒绝、错误凭证、过期均无资金副作用；同键重放原结果。
