# U1—U5 程序内使用说明（本机已配置环境）

本说明对应本轮新增的“普通用户尽量不输入终端命令”路径。仍为**本地模拟银行**，不连接真实银行、真实支付或真实商户；不是安装包，也不包含云部署或开机自启。

**2026-10-26更新：** AUD-06修订时间约束、AUD-07后台租约边界已修复；主目录635项回归与5项干净检查通过。支持完整自然语言生日时间链及单笔/定时备注。手机独立验收入口与当前限制见[收尾报告](2026-10-26收尾1至4验收.md)，现场手机操作仍待本人签收。

## 1. 双击打开

在项目根目录双击 **`启动银行助手.py`**。

- 程序优先使用项目已有的 `.venv`，不自动安装依赖。
- 已有一份页面服务时只打开现有页面，不启动第二套服务。
- 端口被其他程序占用时会显示可读提示，不启动第二套服务，也不改动数据库。
- 正常使用不要求先打开终端。全新电脑的依赖安装/独立安装包仍不在本轮范围；若提示缺少依赖，请按安装说明准备 `.venv` 后再双击。

页面地址为 `http://127.0.0.1:8501`，仅绑定本机回环地址。

## 2. 首次设置（U1）

首次打开且尚未建号时，左侧显示“首次使用”。依次完成：

1. 输入用户名、设置密码（12—256字符）并再次输入；两次不一致会提示，不会建号。
2. 点击“创建本机账号并生成恢复码”。
3. **离线保存一次性恢复码**（建议抄写到本机之外的安全位置）；不要发到聊天、截图给AI、上传网盘或放进网址。
4. 勾选“我已保存”后，页面显示手机验证器二维码；用手机验证器扫码，输入手机当前动态码完成绑定。

安全与续接行为：

- 账号只允许在本机回环页面初始化，已有账号绝不会被覆盖；重复点击或两个页面同时设置也只会建一个账号。
- 恢复码确认前刷新/关闭页面，可用密码继续查看**同一组**恢复码，不会重新发放额外的可用码；确认后页面不再显示明文。
- 已建号但未确认恢复码或未绑定手机时，不会进入真实业务；刷新后继续完成设置。
- 密码、恢复码、二维码和动态码不经过AI对话、模型设置、URL或应用日志。当前页面是模拟银行；真实资金不存在。

## 3. 日常业务与验证（U2）

- 登录只需用户名和密码；登录本身不批准付款。
- 转账等业务仍显示服务端核对的收款对象、金额和动作，按原规则走绿色查询、黄色确认、红色强验证。
- 红色业务要求输入手机验证器**当前动态码**；同一动态码不能重放，连续五次失败锁定本次操作。
- 错误码、过期和锁定会显示可执行提示；过期挑战不会付款，结果未知时先查询原操作，不重复发起。
- 登录会话过期后重新登录，原操作记录仍在本机。重新登录不会自动付款；到对应页面恢复原操作后仍需重新确认/验证。
- 丢手机：使用**密码＋一枚未使用的恢复码**撤销旧绑定和旧会话，再用新手机扫码绑定。恢复本身不批准任何付款；恢复码一次性，旧会话立即失效。
- 密码也遗忘时不能自助恢复；本程序不提供“忘记密码后门”或清空配置继续付款的旁路。

## 4. 后台检查（U3）

在“后台任务与通知”或首页侧栏：

- 点击“启用后台检查”，程序在本机后台检查到期事件；此后关闭浏览器标签页仍可继续。
- 选择会保存；之后重新打开应用并登录时会恢复偏好。重复点击、刷新或多个页面不会启动多个后台。
- 状态区显示是否运行、最近检查时间和真实错误；“启动失败”会保留为可见错误，可重试。
- 点击“停止后台检查”后不再领取新任务；已经开始的检查会完成，已开始/未知的原操作仍保留在待办中供核实。停止不会取消已登记计划，也不会自动付款。
- 程序只通过本应用自己的数据库租约停止本应用后台，不按PID终止其他程序。

## 5. 退出应用与关闭网页（U4）

- **关闭浏览器标签页/网页**：只离开页面；已启用的后台检查继续运行。
- **正常退出应用**：页面侧栏“退出应用（不是关闭网页）”→ 查看未完成待办 → 确认退出。程序会先请求本应用后台停止，确认后才结束本机页面服务。
- 正常退出不会删除余额、流水、预留、计划、通知或待办；重新打开后仍在。
- 直接关闭启动窗口、电源中断或异常退出可能无法完成退出提示；数据库不会因此被重置。重新打开后可继续核对；如果后台未确认停止，下一轮可用“退出应用”或重新启停处理。
- 停止后台或退出应用**不等于**取消已登记任务，也不批准付款。

## 6. 当前边界与未验证范围

- 本轮交付的是 Windows 本机已配置环境中的可双击入口和程序内流程；**不是全新电脑安装包**，没有云部署、系统服务、开机自启。
- 自动化自测使用临时模拟库，不接触日常 `runtime` 数据库、成员原件、桌宠文件或真实凭证；没有真实模型调用。
- 委派隔离环境只有标准库，**无法运行 Streamlit 实际页面与真实 pyotp/qrcode 集成**；本轮用临时 TOTP 协议替身验证服务层逻辑，最终完整依赖页面检查由 Codex 执行。
- 用户本人手机扫码、输入动态码和最终体验签收需用户本人完成，自动化结果不能替代。
- 页面只在 `127.0.0.1` 回环地址提供；不支持把开发服务器暴露到公网/LAN。首次设置同时要求服务绑定回环地址与回环Host，信息缺失时拒绝建号，但这不等于生产级身份系统或银行安全认证。
- 桌面通知、短信、邮件、第三方消息渠道未接入；通知为持久站内待办。电脑关机/休眠期间不承诺准时执行。
- 现有退款、预算、商户、理财和定时规则继续沿用；本程序仍不提供长期无人值守付款授权。
